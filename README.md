# SpaceShooter-WebGameChallenge

## Introduction
SpaceShooter-WebGameChallenge is an exciting web-based game where players navigate a spaceship, avoid enemies, and aim for the highest score. Built using the Godot Engine, this game offers a thrilling experience with engaging visuals and sound effects.

## Features
- Dynamic gameplay with increasing difficulty.
- High score tracking for individual users.
- Responsive design for web platforms.
- Immersive sound effects and background music.

## Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the project in the Godot Engine.
3. Run the game using the Godot editor or export it for the web.

## Play the Game

You can play the game directly in your browser by visiting the following link:

[Play SpaceShooter-WebGameChallenge](https://spaceshooter-wbgame.netlify.app/)

## Usage
- Use arrow keys or WASD to control the spaceship.
- Press the spacebar to shoot lasers.
- Avoid enemy ships and obstacles to survive.
- Aim for the highest score and challenge your friends!
